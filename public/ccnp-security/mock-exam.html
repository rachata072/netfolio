      1. A security team connects a new sensor to a switch SPAN port and configures it to drop exploit traffic. Attacks still reach the servers. What is the cause? Choose one.

        1. The sensor needs Snort 3 instead of Snort 2
        2. A SPAN-fed sensor only receives a copy of traffic, so it can alert but never block
        3. SPAN ports cannot carry encrypted traffic
        4. The intrusion policy is set to Balanced Security and Connectivity
        Show answer

        Answer: B. Only an inline device can drop the original packet. A sensor on a SPAN port gets a copy after the real packet has already been forwarded, so it behaves as an IDS no matter how its policy is set. Review topic 2.1 in the notes →

      2. NGFW inspection must be added between a server VLAN and its existing default gateway. Server and router IP addresses cannot change. Which firewall mode meets the requirement? Choose one.

        1. Routed mode
        2. Transparent mode
        3. Multiple context mode
        4. Passive mode
        Show answer

        Answer: B. Transparent mode makes the firewall a Layer 2 bump in the wire: interfaces join a bridge group and the management IP lives on the BVI. Hosts keep their gateway, yet full access control and IPS still apply. Review topic 2.1 in the notes →

      3. Which two statements about Cisco Secure Firewall Threat Defense high availability are true? Choose 2.

        1. FTD supports active/standby failover
        2. FTD supports active/active failover with failover groups
        3. FTD clustering lets several units act as one logical firewall
        4. FTD high availability requires multiple context mode
        5. FTD failover requires the units to run different software versions
        Show answer

        Answer: A, C. FTD failover is active/standby only, and clustering combines units into one logical device for scale and resiliency. Active/active failover is an ASA feature that depends on multiple context mode. Review topic 2.1 in the notes →

      4. On an IOS XE router, interfaces G0/0 (zone INSIDE) and G0/1 (zone OUTSIDE) have a zone-pair with an inspect policy. G0/2 was never assigned to a zone. What happens to traffic from G0/2 to G0/0? Choose one.

        1. It is permitted because G0/2 has no policy
        2. It is inspected by the INSIDE-OUTSIDE zone-pair
        3. It is dropped because traffic between a zone member and a non-zone interface is never allowed
        4. It is passed statelessly
        Show answer

        Answer: C. With ZBFW, an interface in a zone cannot exchange traffic with an interface that is in no zone. Assign G0/2 to a zone and create a zone-pair to allow it. Review topic 2.1 in the notes →

      5. A router is configured with logging trap 4. Which messages are sent to the syslog server? Choose one.

        1. Only severity 4
        2. Severities 4 through 7
        3. Severities 0 through 4
        4. Severities 0 through 3
        Show answer

        Answer: C. The configured level includes itself and every more severe level, and lower numbers are more severe. Level 4 (warnings) therefore sends 0 through 4. Review topic 2.2 in the notes →

      6. The NMS team must be sure every critical device notification is received, even across a lossy WAN. Which SNMP mechanism should they use? Choose one.

        1. Traps
        2. Informs
        3. GetBulk requests
        4. Community strings
        Show answer

        Answer: B. Informs are acknowledged by the manager and retransmitted until confirmed. Traps are fire-and-forget. Review topic 2.2 in the notes →

      7. An operations team wants interface counters from 500 switches every 10 seconds, with less device CPU load than today's SNMP polling. What should they deploy? Choose one.

        1. NetFlow v5
        2. Model-driven streaming telemetry
        3. SNMPv3 traps
        4. Syslog at level 7
        Show answer

        Answer: B. Streaming telemetry pushes structured YANG data periodically or on change. It scales far better than polling and costs the device less CPU. Review topic 2.2 in the notes →

      8. A SIEM confirms that an endpoint is beaconing to a known C2 server. Which two components let the SIEM automatically quarantine that endpoint on the network? Choose 2.

        1. pxGrid
        2. ISE Adaptive Network Control with CoA
        3. NetFlow v9 templates
        4. SNMP informs
        5. Syslog severity 0
        Show answer

        Answer: A, B. The SIEM signals ISE over pxGrid. ISE applies an Adaptive Network Control policy and uses Change of Authorization to restrict the session. This is Rapid Threat Containment. Review topic 2.2 in the notes →
