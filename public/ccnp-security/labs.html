Packet Tracer and IOS labs

Free hands-on labs for SCOR 350-701 v2.0. Packet Tracer labs give you a network that works but was built the lazy way: download it, harden it step by step, and prove every control. Real IOS labs cover what Packet Tracer can't simulate, such as TACACS+ debugging: build it, break it on purpose, and read the fault from the output. Either way you use the same show commands you'd use on the job.

Available labs (6)

  1. PTSegmentation & Layer 2 Hardening LabDownload a working but insecure switched network and harden it step by step: management baseline, VLANs, trunks, port security, BPDU Guard, protected ports and unused-port lockdown.2.360 to 90 min · download .pkt + .pka
  2. PTLayer 2 Attack Prevention LabAttack a small switched network, then defend it phase by phase with DHCP snooping, Dynamic ARP Inspection, BPDU Guard, Root Guard and storm control. Real Packet Tracer output explained line by line, with every real IOS vs. Packet Tracer difference called out.2.32 to 3 hours · download .pkt + .pka

  4. IOSSNMPv3 Lab: authPriv, snmpwalk and snmpsetConfigure SNMPv3 with SHA and AES on an IOS XE router, poll it from a Linux host with snmpwalk, change its hostname with snmpset, and read every SNMPv3 error.2.745 to 60 min · IOS XE router + Linux with Net-SNMP
  5. IOSNETCONF and RESTCONF Lab: YANG Data with curl and PythonEnable RESTCONF over HTTPS and NETCONF over SSH on IOS XE, confirm the YANG processes are ready, and read live data with curl, Python requests and ncclient.2.745 to 60 min · IOS XE router + Linux with Python 3
  6. IOSAuthenticated NTP Lab: HMAC-SHA-256 Between Two RoutersConfigure an authenticated NTP server and client on IOS XE, watch the client go from stratum 16 to synchronized, and prove the key match from the debug and association detail.2.730 to 45 min · Two IOS XE routers

How every lab works

  • Read the notes first. Each lab belongs to a lecture that explains the attacks and why each defense exists.
  • Packet Tracer labs: download the baseline. A .pkt file for Cisco Packet Tracer (free with a Cisco Networking Academy account). Some labs add a .pka activity with the instructions built in. Every file lists its SHA-256 hash.
  • Real IOS labs: pick an environment. Cisco Modeling Labs, a DevNet or dCloud sandbox, or your own router. Each lab lists what it needs and how to set up the server side.
  • Do, see, prove. Every step tells you what to type, shows the output to expect with the lines that matter explained, and covers which attack or failure it addresses.
  • Answer configs are hidden until you open them, so try it yourself first.

What Packet Tracer can't do

Packet Tracer simulates IOS, so a few real-IOS commands, attack tools like Yersinia and macof, and products such as FTD, ISE and Secure Access aren't available. Each lab lists what's missing and how to practice it in Cisco Modeling Labs or on real gear.
