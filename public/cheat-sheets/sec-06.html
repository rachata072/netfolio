The 15 Enterprise tactics

Read an ID

T1110.003 is technique T1110 (Brute Force), sub-technique .003 (Password Spraying).

  • TA: tactic, the goal
  • T: technique; .00x is a sub-technique
  • M: mitigation
  • G and S: threat group and software

Use it right

Authorized use only. Emulate attacks only in your lab or with written permission.

Caution. IDs change between versions (T1562 is now T1685). Note the ATT&CK version you used.

Remember

  • Tactic = why; technique = how
  • MFA appears in many mitigations
  • Map every alert to a technique ID
