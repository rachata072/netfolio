Run box launchers

Press Win + R, type the name, and press Enter. Ctrl + Shift + Enter runs it as admin. lusrmgr.msc and gpedit.msc exist on Pro and Enterprise editions only.

Processes and power

CommandWhat it does
tasklistRunning processes
taskkill /PID 4321 /F cautionForce close
shutdown /r /t 0 cautionRestart now
shutdown /aCancel a shutdown

Caution. /F and /release can lose unsaved work or drop a remote session. chkdsk C: /f runs at the next reboot. Tell the user first.

Danger zone

Danger. These erase or overwrite data. Double-check the drive letter or path and have a backup.

CommandEffect
format D:Wipes the volume
diskpart, then cleanDeletes every partition
robocopy src dst /MIRDeletes extra files at the destination
del /s /q *.*Deletes silently, no Recycle Bin
regeditOne wrong key can stop boot

Handy: cmd /? shows help, Tab completes paths, | clip copies output, > log.txt saves it.

Remember

  • Run DISM first, then sfc /scannow if files are corrupt
  • 169.254.x.x after /renew means no DHCP server replied
  • .msc is a console snap-in; .cpl is a Control Panel item
  • Use an admin prompt only for the task, then close it
