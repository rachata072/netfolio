7 OSI layers and 4 TCP/IP layers

The sender works down from layer 7 to layer 1; the receiver works back up from 1 to 7.

Encapsulation

On the way down, each layer wraps the one above it. On the way up, the receiver strips each header in reverse.

PDULayerWhat it carries
DataL7 to L5Application data
SegmentL4Ports + data
PacketL3IP addresses + L4 header + data
FrameL2MAC addresses + L3 + L4 + data + FCS trailer
BitsL1The frame as a signal, for example 1011 0010 0110 1101

Troubleshoot bottom-up

Cisco IOS and Windows commands, in the order you would run them.

LayerCommandWhat it answers
1show interfaces statusErrors, duplex
1shutdown then no shutdown cautionBounce the port

3show ip interface briefUp/up? Right IP?
3ping, traceroute, tracertWhere does the path break?
4Test-NetConnection 192.0.2.10 -Port 443Is the port open?

Caution. shutdown drops every session on that port. Never bounce the link you are managing the device from.

Remember

  • L1 to L7: Please Do Not Throw Sausage Pizza Away
  • L7 to L1: All People Seem To Need Data Processing
  • PDUs: Data, Segment, Packet, Frame, Bits
  • Switch = L2 (MAC). Router = L3 (IP).
  • UDP's layer 4 PDU is a datagram. DNS also uses TCP 53 (zone transfers and large answers).
  • * ARP sits between L2 and L3; TLS is often placed at L6.
