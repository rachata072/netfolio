TCP is reliable and uses a handshake: web, SSH, mail, SMB. UDP is fast with no handshake: DNS, DHCP, NTP, VoIP. DNS also uses TCP 53 for zone transfers and big replies. Source: RFC 6335.

Firewall rules of thumb

Danger. Never open these to the internet: 23 Telnet, 135 to 139, 445 SMB, 3389 RDP, 1433, 3306 and 161 SNMP.

  • Default: deny all inbound, allow only what a service needs.
  • Remote access: RDP or SSH through a VPN or gateway with MFA.
  • Verify: a port is a hint, not proof. Check the service.
  • Log: log denied traffic and review it weekly.

Remember

  • FTP: 21 is control, 20 is data (active mode)
  • SNMP: 161 is the manager polling, 162 is traps
  • RADIUS is UDP, TACACS+ is TCP 49
  • DHCP: server 67, client 68, both UDP
  • Mail: 25 server to server, 587 client sends
  • SSH 22 also carries SFTP and SCP
