6 patterns that fix most prompts

Add these to the six parts from the AI-01 sheet.

#PatternUse it whenPrompt starter
1Few-shotYou need the same format or style every timeGive 3 to 5 varied input and output examples
2Step by stepTroubleshooting, math or anything with logic"Reason step by step, then give the final answer."
3Structured outputThe answer feeds a script, table or ticketReturn only JSON with keys: cause, fix, risk

Structured output tips

  • Name the exact keys and allowed values
  • Say "JSON only, no extra text"
  • Allow null or "unknown" instead of guessing
  • Parse and validate before you use it
  • Show one finished example

Stack them: one prompt, four patterns

Example for SOC log triage:

  • Role: You are a SOC analyst. Task: Triage the lines in <logs>.
  • Few-shot: <example>denied tcp 198.51.100.7 to 192.0.2.10:22 => ACTION</example>
  • Step by step: Reason through each line first.
  • Structured: Then return JSON: [{"line": "...", "label": "ACTION|ROUTINE", "why": "..."}]
  • Critique: Re-read your labels once and fix any mistakes.

Combine them

  • 1 + 3: examples that all end in the same JSON shape
  • 2 + 4: think it through, then review before the final answer
  • 6 + 5: ask questions first, then run the chain
  • 3 + 4: ask it to check its JSON against your keys

Wrap examples in tags and keep them varied so the AI does not copy one.

Use patterns safely

Aligned with the OWASP LLM Top 10 (2025).

Danger. Never run AI-written commands on production unread. Test them in a lab.

Caution. Validate JSON and commands before a script uses them. AI output is untrusted input.

Caution. Mask real data in your examples. Tag pasted text as data, not instructions.

Remember

  • 3 to 5 varied examples beat a long rule list
  • Step-by-step text can sound sure and be wrong
  • One pattern at a time: test, then combine
