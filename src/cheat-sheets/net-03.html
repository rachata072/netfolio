Solve any IP in 4 steps

Example: 192.0.2.77/27.

StepDo thisResult
1Write the mask for /27255.255.255.224
2Block size = 256 minus 22432
3Network = the multiple of 32 at or below 77192.0.2.64
4Broadcast = next network minus 1192.0.2.95

Usable hosts are .65 to .94 (30 hosts). The gateway is usually the first address: .65.

VLSM: carve 192.0.2.0/24

Remember

  • Mask octets: 128 192 224 240 248 252 254 255
  • Network and broadcast addresses are not usable hosts
  • A PC with 169.254.x.x never got a DHCP lease
  • Wildcard = 255.255.255.255 minus the mask (ACLs, OSPF)
  • /31 gives 2 usable addresses on point-to-point links (RFC 3021)
  • VLSM: sort by size, largest subnet first
