How a SYN scan reads a port

The SYN scan (-sS) is the default when you run Nmap as root or admin.

Nmap sendsTarget repliesPort state
SYNSYN/ACKopen
SYNRSTclosed
SYNNo replyfiltered

An ICMP unreachable also means filtered. On an open port Nmap answers the SYN/ACK with RST, so the handshake never completes ("half-open").

StateMeaning
openAn application accepts connections
closedReachable, nothing listening
filteredA firewall blocks the probe
unfilteredACK scan: state unknown
open|filteredNo reply, common with UDP
closed|filteredIdle scan only

NSE scripts: know the risk

Script categories: safe, default, discovery, intrusive, vuln, brute, dos, exploit.

Danger. The vuln, brute, dos, exploit and all categories can crash services and lock accounts. Use them in scope only.

Caution. Scripts are not sandboxed. Never run unreviewed .nse files.

Timing templates

TemplateName
-T0paranoid
-T1sneaky
-T2polite
-T3normal (default)
-T4aggressive
-T5insane

T3 is the default. The Nmap book recommends T4 on fast, reliable networks. T5 trades accuracy for speed and can overload fragile devices such as printers, PLCs and old switches.

Before you scan

  • Written scope: IPs, dates and hours
  • Emergency contact and excluded hosts
  • Start at T3 with a small port range
  • Save output with -oA

Remember

  • Root or admin runs -sS by default; a normal user gets -sT
  • No -p means the 1,000 most common TCP ports
  • filtered means something dropped the probe
  • -sV checks the real service, not just the port
  • UDP is slow; expect open|filtered
  • Save every scan with -oA for your report
