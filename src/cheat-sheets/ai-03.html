Mask before you paste

  • Secrets: show run | exclude secret|password
  • IP addresses: swap them for 192.0.2.x and 198.51.100.x
  • Names: use user1 and example.com
  • Keys and tokens: delete them, every time

Make the answer checkable

  • "Put every command in a code block."
  • "Only show commands until I confirm."
  • "List what you assumed about my setup."
  • "Link the vendor doc for each command."

Follow-ups that improve any answer

  • "What could go wrong if I run this?"
  • "Give me the rollback steps too."
  • "Explain it like I'm new to this."
  • "Compare both options in a table."
  • "Turn this into a checklist."
  • "What would prove you wrong?"

Use AI safely at work

Danger. Never run an AI-written script or config on production until you have read it and tested it in a lab.

Caution. Use only the AI tools your company approves. Public tools may keep what you paste.

Caution. AI can invent flags and commands. Check each one in the vendor docs.

Remember

  • Paste the real output, masked
  • Say the device, OS and version
  • You own the change, not the AI
